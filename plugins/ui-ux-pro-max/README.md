# ui-ux-pro-max

一个 Agent Plugin：官方 [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)。

为大模型提供专业级 UI/UX 设计智能，内置 79 种 UI 设计风格、192 套配色方案、74 组字体搭配、119 条 UX 规范指南及 25 种图表类型，覆盖 React、Vue、Tailwind、shadcn/ui、SwiftUI、Flutter 等 22 种技术栈。

## 包含核心 Skills

- `ui-ux-pro-max`: 核心设计智能路由器与设计审查决策
- `design-system`: 设计系统规范与 Token 体系制定
- `design`: UI 视觉布局与交互流设计
- `ui-styling`: Tailwind / CSS 深度样式美化与动效规范
- `brand`: 品牌指南、调性一致性与色彩管理
- `banner-design`: 横幅海报与宣传图设计
- `slides`: 演示文稿与幻灯片排版美化

## 使用方式

在已添加 **ixiongdi-ai** 市场的客户端（Codex、Cursor、ChatGPT 桌面版）中：
- Codex：`codex plugin add ui-ux-pro-max@ixiongdi-ai`
- Cursor：Customize 中安装 `ixiongdi/ai` 里的 `ui-ux-pro-max`，或开发软链到 `~/.cursor/plugins/local/ui-ux-pro-max`
