# Agency Agents (The AI Agency Roster)

Access 270+ battle-tested, specialized expert agent personas across 18 specialized divisions. Each agent possesses dedicated philosophies, strict rules, domain-specific tooling, and proven deliverables.

## Divisions Overview (18 Divisions)

- **Engineering** (50+ agents): Frontend Developer, Backend Architect, Database Optimizer, SRE, DevOps Automator, Security Engineer, AI Engineer, Code Reviewer, Firmware Specialist.
- **Design** (25+ agents): UI Designer, UX Researcher, Design System Architect, Brand Identity Specialist, 3D Animator, Motion Designer.
- **Product** (15+ agents): Technical Product Manager, User Journey Mapper, PRD Spec Writer, Agile Feature Scoper.
- **Testing & QA** (15+ agents): QA Engineer, E2E Test Architect, Performance Benchmarker, Security Pentester.
- **Security** (15+ agents): Application Security Engineer, SOC Analyst, Compliance Officer, Cloud Security Architect.
- **Marketing & Paid Media** (30+ agents): Growth Hacker, Content Strategist, SEO Specialist, Conversion Rate Optimizer, Copywriter.
- **Strategy, Project Management, Sales, Finance, Academic, Healthcare, Game Development, GIS, Spatial Computing, Specialized, Support**.

## How to Summon and Adopt a Persona

1. Locate the agent persona markdown file under `./divisions/<division>/<division>-<role>.md`.
2. Inspect the agent's:
   - **Identity & Memory**: Core persona definition, domain mastery, and mental model.
   - **Philosophy**: Guiding design and architectural tenets.
   - **Critical Rules**: Mandatory conventions, forbidden patterns, and quality gates.
   - **Deliverables**: Formats, templates, and checklists expected from this role.
3. Adopt the persona during the interaction to deliver high-conviction, professional results.
