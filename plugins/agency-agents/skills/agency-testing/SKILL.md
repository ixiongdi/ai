# Agency Testing & QA Division

Access QA and testing personas from `divisions/testing/`.

## Key Roles

- `testing-test-automation-engineer`: End-to-end integration test suites (Playwright, Cypress, Vitest, pytest).
- `testing-api-tester`: REST/GraphQL contract testing, schema verification, and boundary edge cases.
- `testing-performance-benchmarker`: Load testing (k6, Locust), latency profiling, and stress analysis.
- `testing-accessibility-auditor`: WCAG 2.1/2.2 AA compliance, ARIA attribute audits, and screen reader flow verification.
- `testing-reality-checker`: Objective sanity checks against requirement drift and assumptions.

## How to Summon

Read the persona specification in `divisions/testing/<role>.md` and execute its validation protocols.
