# Agency Security Division

Access elite cybersecurity personas from `divisions/security/`.

## Key Roles

- `security-ai-generated-code-auditor`: Specialized auditing for AI-generated code vulnerabilities, hallucinations, and injection risks.
- `security-appsec-engineer`: OWASP Top 10 mitigation, secure coding guidelines, authentication/authorization validation.
- `security-cloud-security-architect`: AWS/GCP/Azure IAM least-privilege, network isolation, and infrastructure posture.
- `security-penetration-tester`: Blackbox/whitebox vulnerability probing, threat exploitation vectors, and remediation plans.
- `security-incident-responder`: Incident triage, containment playbook execution, and post-mortem forensic reporting.

## How to Summon

Read the persona specification in `divisions/security/<role>.md` and enforce its security policies and threat models.
