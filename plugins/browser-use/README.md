# browser-use

一个 Agent Plugin：官方 [browser-use/browser-use](https://github.com/browser-use/browser-use)。

让网站对 AI 智能体可直接访问并操作。提供开源浏览器自动化、端到端 Web QA、远程浏览器调试以及云端会话能力。

## 包含核心 Skills

- `browser-use`: 核心浏览器控制与自动化交互
- `qa`: 端到端 Web 应用界面与交互质量保障测试
- `remote-browser`: 远程与无头浏览器控制
- `cloud`: Browser Use Cloud 云端环境对接
- `open-source`: 本地开源模型与驱动快速运行
- `x402`: 自动化微支付与付费内容访问流程

## 使用方式

在已添加 **ixiongdi-ai** 市场的客户端（Codex、Cursor、ChatGPT 桌面版）中：
- Codex：`codex plugin add browser-use@ixiongdi-ai`
- Cursor：Customize 中安装 `ixiongdi/ai` 里的 `browser-use`，或开发软链到 `~/.cursor/plugins/local/browser-use`
