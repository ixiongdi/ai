# ecc

一个 Agent Plugin：官方 [affaan-m/ECC](https://github.com/affaan-m/ECC)（Everything Claude Code）。

全面的智能体性能优化与工程方法系统，提供覆盖智能体架构评估、AI 自主闭环测试、全栈设计与重构等领域的高性能标准化 Skills。

## 包含核心 Skills

- 智能体架构与自评：`agent-architecture-audit`、`agent-eval`、`agent-self-evaluation`、`autonomous-agent-harness`、`autonomous-loops`
- 软件工程与质量：`ai-first-engineering`、`ai-regression-testing`、`backend-patterns`、`api-design`、`architecture-decision-records`
- 全栈与移动端开发：`android-clean-architecture`、`angular-developer`、`browser-qa`、`accessibility`
- 基准测试与性能：`benchmark`、`benchmark-methodology`、`benchmark-optimization-loop`
- 共计收录 292 个专业领域 Skills，完全遵循 [Agent Plugins 1.0](https://agent-plugins.org/) 与 [Agent Skills](https://agentskills.io/) 标准。

## 使用方式

在已添加 **ixiongdi-ai** 市场的客户端（Codex、Cursor、ChatGPT 桌面版）中：
- Codex：`codex plugin add ecc@ixiongdi-ai`
- Cursor：Customize 中安装 `ixiongdi/ai` 里的 `ecc`，或开发软链到 `~/.cursor/plugins/local/ecc`
