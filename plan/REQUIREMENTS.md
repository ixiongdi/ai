# 项目需求调整

记录日期：2026-09-23。以下为用户确认的最新方向；与现有 README、数据或实现不一致时，以本文件为后续调整依据。本文件记录需求，不表示现有功能或数据已完成更新。

## 1. 按订阅与模型独立核算

- 最小对比单位为「厂商 × 付费订阅档位 × 具体模型版本」，每个组合独立展示和计算。
- 示例：购买 ChatGPT Plus 后使用 gpt-6-luna，单独计算该组合的等效 API 价值与每美元智能交付量。该名称仅为用户举例，是否存在、可订阅使用及 API 定价均需官网核实。
- 展示月订阅费用、该模型可用额度、实际可完成任务量、等效 API 费用（美元）、等效 API 价值／订阅费，以及每 1 美元可获得的智能量（IPD）。
- 单模型 IPD = 实际可完成任务量 × 该模型智能评分 ÷ 月订阅费用。明确评分来源与版本。
- API 折算须注明具体模型、官方 API 单价、输入／输出及缓存等用量假设；不能把消息次数直接当作固定 API 成本。
- 共享额度的模型组合属于独立使用情景，不得相加后宣称为同一订阅可同时兑现的总价值。官方未公布的额度或无法核实的价格标记为未知，不编造精确结果。

## 2. 仅比较付费订阅，并按价格段分组

- 排除免费套餐、免费试用，以及仅按量付费而没有订阅计划的产品。
- 对付费订阅按多个价格段展示、筛选和比较；具体价格段边界待定。
- 区分月付价格、年付折合月价、按席位收费及最低席位要求，避免混用不同购买条件。

## 3. 官网最新订阅数据与近三个月模型

- 每次更新时查询厂商最新官网定价、订阅权益、模型可用性及限额说明，并保留来源链接、抓取日期和适用地区／币种。
- 模型范围按数据更新日滚动限定为最近三个月发布的模型或明确的新版本，不以旧模型资料的更新时间代替模型发布日期。
- 记录模型发布日期及来源；不满足时间窗口的模型移出当前比较范围。
- 现有数据需要重新核实，不能直接视为符合上述时效要求。

## 4. 扩大厂商和计划覆盖

- 扩充各大云服务厂商、AI 厂商及 coding agent 厂商推出的付费订阅计划。
- 同一厂商覆盖多个符合条件的订阅档位，并分别列出可用的近期模型。
- 每项计划核对价格、计费周期、地区、席位、模型访问权限、模型倍率、共享额度、限频、超额收费和来源。
- 仅纳入可核实且符合上述条件的计划；对未纳入的候选记录原因，不以扩大数量为由混入免费或纯 API 按量计费产品。
